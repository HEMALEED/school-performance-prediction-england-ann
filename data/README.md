# Data sources

All files downloaded on 6 July 2026. GIAS is a daily-updated register and the
Ofsted management information is a monthly snapshot (extract: "latest
inspections as at 31 May 2026"), so figures reflect the sources at that date.
These files are not committed to the repository; download them as described
below and place them in this folder with the exact filenames given.

| Filename | Source | How to obtain |

| gias_establishments.csv | DfE, Get Information About Schools | https://get-information-schools.service.gov.uk/Downloads → All establishment data → Establishment fields CSV |

| ks4_2023.csv | DfE performance tables 2022/23 | https://www.compare-school-performance.service.gov.uk/download-data → 2022-2023 → All of England → Key stage 4 results (final) |

| ks4_2024.csv | DfE performance tables 2023/24 | same → 2023-2024 → All of England → Key stage 4 results (final) |

| ks4_2025.csv | DfE performance tables 2024/25 | same → 2024-2025 → All of England → Key stage 4 results (final) |

| ofsted_mi.csv | Ofsted management information | https://www.gov.uk/government/statistical-data-sets/monthly-management-information-ofsteds-school-inspections-outcomes → state-funded schools, latest inspections as at 31 May 2026 (CSV) |

| imd2025.csv | MHCLG, English Indices of Deprivation 2025 | https://www.gov.uk/government/statistics/english-indices-of-deprivation-2025 → File 7: IoD2025 All Ranks, Deciles, Scores and Population Denominators |
